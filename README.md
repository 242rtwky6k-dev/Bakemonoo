# BAKEMONO Web v1

This is the iPhone-first web/PWA version of BAKEMONO.

Features:
- Dark clean UI
- Monday-Saturday split and Sunday rest
- Your gym + armwrestling exercises
- Weight/reps logging
- Previous performance and automatic suggested weight
- PRs
- Body weight
- History
- Progress chart
- Routine editing
- Custom exercises
- Home-screen PWA manifest

This version stores data locally in the browser. True multi-device online sync requires a hosted backend/database and authentication. The next production step is connecting Apple Sign In + a cloud database.
